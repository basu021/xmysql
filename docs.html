XMySQL API Documentation

Basic CRUD Operations

List All Records
GET /api/tableName
curl -X GET http://localhost:3000/api/tableName
[
    {
        "id": 1,
        "name": "Example",
        ...
    }
]
Create Record
POST /api/tableName
curl -X POST -H "Content-Type: application/json" -d '{"field1":"value1","field2":"value2"}' http://localhost:3000/api/tableName
{
    "id": 1,
    "field1": "value1",
    "field2": "value2"
}
Get Single Record
GET /api/tableName/:id
curl -X GET http://localhost:3000/api/tableName/1
{
    "id": 1,
    "field1": "value1",
    "field2": "value2"
}
Update Record
PATCH /api/tableName/:id
curl -X PATCH -H "Content-Type: application/json" -d '{"field1":"newValue"}' http://localhost:3000/api/tableName/1
{
    "id": 1,
    "field1": "newValue",
    "field2": "value2"
}
Delete Record
DELETE /api/tableName/:id
curl -X DELETE http://localhost:3000/api/tableName/1
{
    "message": "Record deleted successfully"
}

Advanced Operations

Bulk Operations
POST /api/tableName/bulk
curl -X POST -H "Content-Type: application/json" -d '[{"field1":"value1"},{"field1":"value2"}]' http://localhost:3000/api/tableName/bulk
{
    "message": "2 records created successfully"
}
Find One
GET /api/tableName/findOne
curl -X GET "http://localhost:3000/api/tableName/findOne?_where=(field1,eq,value1)"
{
    "id": 1,
    "field1": "value1",
    "field2": "value2"
}
Count
GET /api/tableName/count
curl -X GET http://localhost:3000/api/tableName/count
{
    "count": 100
}
Distinct
GET /api/tableName/distinct
curl -X GET "http://localhost:3000/api/tableName/distinct?_fields=field1"
[
    {"field1": "value1"},
    {"field1": "value2"}
]

Authentication

Login
POST /api/auth/login
curl -X POST -H "Content-Type: application/json" -d '{"username":"test","password":"test"}' http://localhost:3000/api/auth/login
{
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
        "id": 1,
        "username": "test",
        "role": "user"
    }
}
Register
POST /api/auth/register
curl -X POST -H "Content-Type: application/json" -d '{"username":"newuser","password":"password"}' http://localhost:3000/api/auth/register
{
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
        "id": 2,
        "username": "newuser",
        "role": "user"
    }
}
